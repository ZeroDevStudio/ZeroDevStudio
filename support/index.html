Account & security

Keep your account access safe.

How do I create a ZeroDev Studio account?

Open the Account page, choose Create account, and enter your name, email address, and a unique password. In the live service, the authentication system sends a one-time confirmation code to your email before the address is verified.

What should I do if I forget my password?

Use the Forgot password option on the account page. The live service will request a password-reset message. Never send your password or verification code to anyone claiming to be support.

✉

Email verification

Understand confirmation codes and delivery.

I didn't receive my verification code. What can I check?

Check the email address you entered, then look in Spam, Junk, or Promotions. Wait before requesting another code. If delivery still fails, the service owner should check the authentication email settings and SMTP provider logs. The demo website does not send real email.

Can I request another verification code?

Yes. The live account screen includes a resend option with a cooldown. A previously issued code may stop working after it expires or a newer code is requested. Use only the newest code and never share it.

Projects & websites

Understand what goes into a website request.

Can I submit a project request right now?

Verified clients can submit a private project ticket after the backend is configured. Use the Start a Project page from the public website. Guest ticket access is not enabled in this release.

Pricing & payments

Understand sample budgets and payment rules.

Are the example prices fixed packages?

No. The $20 starter, ₱5,000 entry-level, and ₱10,000+ premium examples are illustrative starting budgets. The final quotation depends on agreed scope, page count, content, design, and functionality.

Which payment methods are accepted?

GCash is currently the only accepted payment method described by the studio; PayPal is coming soon. Payments are arranged manually after a written quotation and are not collected by this website. Never share your GCash MPIN, password, or OTP.
