# ZeroDev Studio — v0.8 Budget Examples

The public site now links to three fictional sample websites to help visitors understand how a design could scale with different example budgets.

| Example level | Example budget | Illustrative direction |
|---|---:|---|
| Starter | $20 USD (approximately ₱1,275 PHP) | Focused single-page website with core information and a clear action |
| Entry level | ₱5,000 PHP | More developed small-business site with multiple content areas, service information, and contact path |
| Higher scope | ₱10,000+ PHP | More custom visual direction, expanded content structure, and richer interaction potential |

## NEW26 preview

The promotion preview displays a hypothetical 10% discounted value for each tier after NEW26 is applied. The offer remains redeemable once per verified account and applies to one eligible project only. The three shown values are comparisons to help a client understand what a 10% reduction would look like at each budget level; they are not multiple discounts or multiple redemptions.

| Example budget | 10% illustration |
|---:|---:|
| $20 USD | $18 USD (approximately ₱1,148 PHP) |
| ₱5,000 PHP | ₱4,500 PHP |
| ₱10,000+ PHP | ₱9,000+ PHP |

## Important limitations

- These websites are fictional demonstration concepts created for the ZeroDev Studio portfolio.
- Prices are illustrative starting budgets, not fixed packages or guarantees.
- Final quotation depends on the actual agreed requirements, pages, content, features, revisions, and timeline.
- The demos do not include live authentication, data collection, booking, payment, or working enquiry backends.
