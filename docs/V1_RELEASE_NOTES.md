# v1.0 First Release Notes

## Included

- Finalized the public studio website and retained the three illustrative pricing/sample websites.
- Added a real project-intake form for signed-in, email-verified clients.
- Added server-generated project reference numbers (`ZD-YYYY-######`).
- Added private client workspace data loading, ticket status display, quotations, conversation threads, and private attachment download links.
- Added a staff workspace with database-gated active staff membership and role-based ticket update permissions.
- Added client-visible replies and internal staff notes with RLS-separated visibility.
- Added ticket event history and in-app notification records generated by database triggers.
- Added a private Storage bucket with file-type and size restrictions.
- Added a server-side helper to attach a previously redeemed NEW26 10% promotion to one ticket.
- Updated copy so setup requirements and unavailable channels are disclosed accurately.

## Not activated by this ZIP

- Live Supabase project, SMTP credentials, public domain, staff accounts, or production secrets.
- Guest ticket / one-time guest access-link workflow.
- Ticket email notifications and browser push notifications.
- Payment processing or automated GCash/PayPal collection.
- Live human support chat.

## Validation scope

The package was checked for JavaScript syntax, HTML parsing, CSS brace balance, local file references, ZIP integrity, and obvious secret-like strings. These checks do not replace browser testing, SQL execution in a disposable Supabase project, or security testing with separate client/staff accounts.
